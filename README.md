# 專案

### 專案概觀 (Project Overview) 
建立一個名為「十圓方里」（十里方圓）的網頁版合作社管理與電子商務系統。
本系統是一個服務三種核心身分（社員、顧客、股東）的混合型平台 。它必須支援雙軌工作流：「社務系統（合作社行政）」與「業務系統（電商與預購營運）」。

---

#### 🌐 多國語言支援 (Language & i18n Support) 
*   **雙語介面**：支援完整的國際化（i18n），在導覽列/頁首（Navbar/Header）提供 **繁體中文 (Traditional Chinese)** 與 **英文 (English)** 的即時語言切換功能。
*   系統內的所有標籤、選單項目、狀態徽章以及使用者工作流程，都必須根據所選擇的語言無縫渲染。

---

#### 🔑 關鍵角色與身分驗證 (Key Roles & Authentication)
1.  **使用者角色** [cite: 2]：
    *   訪客 / 非社員 (Guest / Non-member)
    *   已驗證社員 (Verified Member)
    *   理監事 / 管理員 (Board / Admin)
2.  **社員入社與身分驗證**：
    *   實名認證工作流。
    *   申請表單 ➡️ 管理員後台審核 ➡️ 強制性「合作社社務教育訓練」進度追蹤 ➡️ 理監事會核准 ➡️ 發放股金與分配唯一社員 ID 。

---

#### 📦 核心模組一：電子商務與供應鏈（零庫存預購與共同購買） 
1.  **社員願望清單與需求彙整 (Member Wishlist & Demand Pooling)**：
    *   社員可以提交商品想法或願望清單，成功採購將獲得獎勵點數（積點） 。
    *   在正式下單前提供「線上意向調查」小工具，以預測廠商庫存。
2.  **無庫存預購機制 (Pre-order Flow)** [cite: 3]：
    *   即時顯示預購數量與「熱銷商品」 [cite: 3]。
    *   社員必須在截止日期前支付訂金或全額以鎖定訂單。訂單截止後 ➡️ 向廠商採購。
3.  **商品與稅務矩陣 (Product & Tax Matrix)** ：
    *   **一級農產品**：免稅 。
    *   **加工食品 / 健康餐盒**：標準稅率（應稅） 。
    *   **非社員銷售限額守護者**：追蹤非社員銷售額限制（必須維持在總營收的 30% 以下）。針對非社員交易，系統會自動計稅並串接第三方支付發票 。
4.  **特殊庫存與物流 (Special Inventory & Logistics)**：
    *   針對不同的 SKU（例如鮮蛋與醬油）設定溫控或特殊處理標記 。
    *   配送方式：現場自取或宅配 [cite: 3]。

---

#### ⚖️ 核心模組二：合作社治理與結餘分配（社務與結餘分配）
1.  **民主治理儀表板 (Governance Dashboard)**：
    *   年度社員大會追蹤器：實作「一人一票」投票模組。
    *   每半年召開的社務會議記錄器。
    *   社員教育學習專區。
2.  **結餘與回饋計算機 (Surplus Engine)**：
    *   財務分類帳，將總營收扣除成本後，劃分為公積金（50% 合作資本/公積金）與社員分配金。
    *   將剩餘結餘（50%）依據**社員消費貢獻度（累積點數）**而非僅依持股比例進行分配。

---

#### 🎨 UI / UX 設計要求
*   現代、乾淨且友善的設計，反映健康、永續與社群信任。
*   響應式版面配置，具備單一入口，可在社員門戶與行政管理控制台之間無縫切換。
*   中文與英文的訂單狀態互動標籤：
    *   `[Surveying / 意象調查中]` ➡️ `[Pre-ordering / 預購中]` ➡️ `[Sourcing / 廠商進貨中]` ➡️ `[Ready for Pickup/Delivery / 待取貨]`
